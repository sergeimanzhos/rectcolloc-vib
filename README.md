# Rectangular collocation for molecular vibrations with potential-gradient rows

Rectangular (M > N) collocation for J = 0 vibrational levels with an exact Cartesian finite-difference
kinetic-energy operator, optional potential-derivative (gradient) rows, and IR intensities.
Applied here to Cl2CO on a neural-network PES.

## Contents

- `skill/rectangular-collocation-vib/SKILL.md`: the procedure as a Claude skill.
- `cl2co/`: Cl2CO code and data.

### Cl2CO code (`cl2co/`)

| File | Purpose |
|---|---|
| `pes.py`, `fitNN100NNs4.dat`, `Cl2COpes.m` | NN PES (Python port of the MATLAB evaluator; parameters in the .dat file) |
| `eq.py` | Equilibrium geometry and Hessian on the PES; writes `eq.npz` |
| `coords6.py` | Eckart-frame dimensionless normal coordinates, X(q), q(X), volume element rho(q) |
| `r2.py` | R_d (R2) quasi-random sequence |
| `collo6.py` | Gaussian basis, exact KEO by 5-point Cartesian FD, gradient rows, accumulated S/H, shift-invert solver, residuals |
| `run.py` | Driver: `python3 run.py N vmax cfg p fac ec "M1,M2,..." tag` (p = gradient-row fade exponent, best p = 3) |
| `ir6.py` | IR intensities from collocation wavefunctions (`DIP=dipole_file.npz python3 ir6.py tag N vmax`) |
| `dipder.py` | B3LYP linear dipole derivatives (PySCF) |
| `dipder_cc.py` | CCSD(T) finite-field dipole derivatives (PySCF), resumable |
| `vp_dft.py`, `vp_fit.py`, `vp2.py`, `vp_nn.py` | Numerical 6-mode GVPT2: DFT stencil (incl. f_1256 points), force-field fit, resonance polyads, intensities; `vp_nn.py` builds the same stencil on the NN PES for validation |
| `summary_figs.py`, `figs.py`, `plot_*.py` | Figures |
| `*.sh` | Batch scripts used for parameter scans |

### Data

| File | Content |
|---|---|
| `reference.txt` | Reference vibrational levels on the NN PES (cm-1) |
| `eq.npz`, `box.npz` | Equilibrium/Hessian; sampling box |
| `dipder*.npz` | Linear dipole derivatives: B3LYP/aug-cc-pVDZ, B3LYP/aug-cc-pVTZ, CCSD(T)/aug-cc-pVDZ |
| `pts_20000000_1150_{N}.npz` | Basis-function centres for N = 2000, 5000, 10000 |
| `exp_digitized.csv` | Digitized experimental IR absorbance (from a published figure) |

Collocation point sets (`pts_1_*.npz`) are regenerated by `run.py` when absent.

## Best settings found (Cl2CO, NN PES)

Widths (0.857375, 0.857375, 0.95, 0.9025, 0.95, 0.95); Ec = 1150 cm-1; Vmax = 5000 cm-1 (N ≤ 5000) or 5500 (N = 10000);
box at 6500 cm-1; gradient rows weighted by (1 − V/Vmax)^3; 2000 validation points.

Requirements: Python 3, numpy, scipy, numexpr, matplotlib; PySCF for the DFT/CCSD(T) scripts.
